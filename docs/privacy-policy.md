# Privacy Policy

_Public GitHub Pages copy for Chrome Web Store listing use. Keep this page in sync with `/PRIVACY.md`._

_Last updated: February 13, 2026_

## Scope

This policy covers the Multi Agent Council Chrome extension and its public repository.

## What data is processed

The extension processes content you type or attach in the side panel, plus content captured from provider pages (ChatGPT, Gemini, Claude, Grok) in order to run Single/Compare/Debate flows.

## Where data is stored

- Chat history is stored locally on your device (IndexedDB) by the extension.
- Optional passphrase protection encrypts protected chat content at rest.
- Unlock keys are stored in Chrome session storage and are cleared when the browser session ends.

## What is not sent by this project

- The extension does not run a project-operated backend service for message relay.
- Prompts/responses are sent directly through provider web UIs using browser automation.

## Third-party providers

When you use provider tabs, your content is subject to each provider's own terms and privacy practices.

## Security notes

- You are responsible for the browser profile where the extension runs.
- Avoid attaching sensitive files unless required.
- Use passphrase protection for local-at-rest protection.

## Your controls

- Delete chats from the extension UI.
- Lock protected chats.
- Reset/clear history data from settings.

## Contact

For privacy questions, open a GitHub issue for non-sensitive topics. For sensitive/security topics, follow the security policy.
