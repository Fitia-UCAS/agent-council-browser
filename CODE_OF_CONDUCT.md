# Code of Conduct

## Our Commitment

We are committed to making participation in this project respectful, safe, and constructive for everyone.

## Expected Behavior

- Be respectful and assume good intent.
- Focus feedback on code and behavior, not people.
- Keep discussions technical, clear, and actionable.
- Report security issues privately as described in `SECURITY.md`.

## Unacceptable Behavior

- Harassment, insults, or personal attacks.
- Discriminatory language or exclusionary behavior.
- Publishing private/sensitive information without consent.
- Any malicious activity targeting contributors or users.

## Enforcement

Maintainers may remove comments, reject contributions, or restrict access for behavior that violates this code.

## Scope

This policy applies to project spaces (issues, pull requests, discussions, review comments) and related community channels.
